# Hybrid LoRaWAN and LEO Satellite Backhaul for Disaster-Resilient Agri-IoT

Simulation code for the paper:

**"Techno-Economic Analysis of Terrestrial and Non-Terrestrial Networks for Disaster-Resilient Agri-IoT Systems"**  
Niken Suryantoro — MSc Telecommunications, University College London (UCL), 2026

## Overview

This repository contains three simulation notebooks evaluating a hybrid LoRaWAN and LEO satellite backhaul architecture for oil palm plantation IoT in Indonesia. The simulations assess network performance, satellite link availability under tropical weather conditions, and the economic viability of the proposed hybrid system.

## Repository Structure

```
├── step1_lorawan_final.ipynb          # LoRaWAN discrete-event simulation
├── step2_satellite_final.ipynb        # LEO satellite link budget simulation
├── step3_hybrid_decision_system.ipynb # Rule-based hybrid decision system
├── requirements.txt                   # Python dependencies
└── README.md
```

## Notebooks

### Step 1 LoRaWAN Simulation
Discrete-event simulation of a LoRaWAN network over a 5,377 ha oil palm plantation in South Kalimantan. Evaluates Packet Delivery Ratio (PDR), collision rate, and weak signal rate across varying node densities (100–1,000), spreading factors (SF7, SF9, SF12), and TX intervals (300–3,600 s).

### Step 2 LEO Satellite Simulation
Link budget simulation of a LEO satellite backhaul using Starlink Gen-1 parameters, ITU-R P.838 rain attenuation model, and a four-state Markov chain weather model (clear, light rain, moderate rain, heavy rain). Evaluates link availability and latency across 100 simulation seeds.

### Step 3 Hybrid Decision System
Rule-based decision system that determines the optimal connectivity mode (LoRaWAN-only, hybrid, or satellite-only) every 30 minutes based on LoRaWAN PDR and satellite link availability. Evaluated across three scenarios: baseline, light stress, and heavy stress.


## Requirements

Python 3.9 or later is recommended.

Install dependencies with:

```bash
pip install -r requirements.txt
```


## How to Run

Run the notebooks in order:

```
Step 1 → Step 2 → Step 3
```

Step 3 reads output CSV files generated by Step 1 and Step 2. If those CSV files are not present, Step 3 will run its own simulation automatically.

To run a notebook:

```bash
jupyter notebook step1_lorawan_final.ipynb
```

Or open all notebooks in Jupyter Lab:

```bash
jupyter lab
```

## Key Parameters

| Parameter | Value |
|---|---|
| Simulation area | 5,377 ha (53.77 km²) |
| LoRaWAN frequency | AS923 (923 MHz) |
| Satellite constellation | Starlink Gen-1 (550 km altitude) |
| Satellite frequency | 12 GHz (Ku-band) |
| Rain attenuation model | ITU-R P.838 |
| Simulation duration | 86,400 s (24 hours) |
| Decision window | 30 minutes |
| Random seed | 42 (baseline) |
